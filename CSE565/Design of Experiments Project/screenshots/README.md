# Report Evidence

Store report screenshots in this folder using these names:

- `pict_model_and_output.png` - PICT model, command, and generated suite.
- `chatgpt_prompt_and_response.png` - exact ChatGPT prompt and generated suite.
- `pairwise_verification.png` - independent validation output for both suites.

Keep screenshots readable at normal PDF size. Crop out unrelated desktop content, but retain enough context to show the tool and its result.
