# Report Evidence

Store report screenshots in this folder using these names:

- `pictcommandoutput.png` - PICT command and generated suite.
- `chatgptoutput.png` - exact ChatGPT prompt and generated suite.
- `pairwise_verification.png` - output of `make verify`, showing independent validation for both suites.

Keep screenshots readable at normal PDF size. Crop out unrelated desktop content, but retain enough context to show the tool and its result.
