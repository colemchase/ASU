1. Algorithm Development

For this project, I implemented the Heapsort algorithm in Python. The program defines a heap class that stores a copy of the input list, builds a max heap, repeatedly swaps the largest item to the end of the unsorted section, and shrinks the heap boundary until the list is sorted.

The implementation is stored in heap_sort.py. To use it, create a heap object with an input list, call heapify(), and then read the sorted result from h.arr.

Heapsort Code

"""Heapsort implementation for the CSE 565 unit testing project."""
class heap:
    def __init__(self, arr=[]):
        self.arr = list(arr)

    def swap(self, endex):
        if endex > 1:
            temp = self.arr[0]
            self.arr[0] = self.arr[endex-1]
            self.arr[endex-1] = temp

    def build_max_heap(self, i, endex):
        # build max heap from the array until endex
        if i < endex:
            l = 2 * i + 1
            r = 2 * i + 2
            self.build_max_heap(l, endex)
            self.build_max_heap(r, endex)
            if l < endex:
                if self.arr[l] > self.arr[i]:
                    temp = self.arr[i]
                    self.arr[i] = self.arr[l]
                    self.arr[l] = temp
            if r < endex:
                if self.arr[r] > self.arr[i]:
                    temp = self.arr[i]
                    self.arr[i] = self.arr[r]
                    self.arr[r] = temp

    def heapify(self):
        for i in range(len(self.arr)):
            self.build_max_heap(0, len(self.arr)-i)
            self.swap(len(self.arr)-i)

2. Unit Testing Framework and AI Prompt Generation

I used Python's built-in unittest framework. This framework was selected because it is included with Python, does not require external dependencies, and supports clear assertions for expected sorting behavior.

A generative AI tool was used to create the first set of unit tests. The prompt explained how the Heapsort implementation is used and asked the AI to generate unit tests for common and edge-case inputs.

AI Prompt

I wrote a Python Heapsort implementation for a software unit testing project.
The code defines a class named heap. To use it, create h = heap(input_list),
call h.heapify(), and then check h.arr for the sorted result.

Please generate Python unittest test cases for this Heapsort implementation.
Cover normal input and edge cases, including an empty list, one-element list,
already sorted list, reverse-sorted list, duplicate values, negative numbers,
mixed positive and negative numbers, and all equal values.

4. Assessment and Improvement of Test Cases

The AI-generated tests were a good starting point because they covered several common sorting scenarios. However, the generated suite was still limited. It did not check whether the original input list was preserved, did not include randomized testing, and did not compare many different generated inputs against a trusted sorting function.

I improved the test suite in test_heap_sort_student.py. The improved tests keep the original coverage and add stronger checks for input preservation, mixed float and negative values, a larger reverse-sorted list, and randomized lists compared against Python's built-in sorted function.

5. Assessment of the Generative AI Tool

The generative AI tool was useful for quickly creating a basic unit test suite. It correctly understood the class interface, used Python's unittest framework properly, and generated tests for important basic cases such as empty lists, duplicates, negative numbers, and reverse-sorted lists.

The main weakness was that the AI-generated tests were mostly example-based. They verified specific inputs and outputs, but they did not deeply test broader properties of a sorting algorithm. For example, the first generated test suite did not check whether the input list remained unchanged and did not use randomized comparisons against a known correct sorting function.

Overall, the AI tool was effective as a starting point, but human review was still necessary. The AI helped create a working baseline, while the student-improved tests made the suite stronger and more convincing.

Conclusion

This project implemented Heapsort, tested it with AI-generated unit tests, executed those tests successfully, evaluated their limitations, and improved the test suite with additional student-created tests. Both the AI-generated suite and the improved student suite passed.
