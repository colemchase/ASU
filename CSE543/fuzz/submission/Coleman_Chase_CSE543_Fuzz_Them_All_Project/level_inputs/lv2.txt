For this level, I reused my mutation based fuzzer from level 1 against the new /challenge/prog binary. The fuzzer generated long mutated inputs containing repeated characters and numeric edge cases such as 1, -1, and 0, then monitored the program for crashes. It found a 423 byte input that caused a segmentation fault, so I saved that input as crash_0 and verified it with /challenge/challenge < crash_0, which reproduced the crash and returned the flag.
