# CSE 572

## Projects

This course folder contains three data mining / machine learning projects based on continuous glucose monitor (CGM) and insulin pump data.

- `Extracting Time Series Properties of Glucose Levels in Artificial Pancreas Project`
- `Machine Model Training Project`
- `Cluster Validation Project`

## Shared Data Theme

The supplied project ZIPs include Medtronic-style CGM/insulin CSV exports. Common important columns include:

- `Date`
- `Time`
- `Sensor Glucose (mg/dL)`
- `ISIG Value`
- `Alarm`
- `Suspend`
- `BWZ Carb Input (grams)`
- `Bolus Volume Delivered (U)`
- `Basal Rate (U/h)`

The projects appear to progress from feature extraction, to supervised model training, to clustering/cluster validation.
